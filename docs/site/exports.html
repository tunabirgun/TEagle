Use the contextual export controls

Right-click tables, features and gel bands for context-specific actions. Depending on the result, you can copy a row, extract a sequence or its flanks, send coordinates to primer design, or export the selected output.

Prefer vector formats for diagrams you will resize. Keep the accompanying table for numerical inspection.

Retain coordinates and context

The header can switch displayed coordinates between 0-based half-open and 1-based inclusive. Exports keep their documented conventions. Check that convention before using a region in another tool.

Analysis records preserve software and database versions, parameters, input identity and explicit run states. Keep the associated records with derived figures so that a partial or withheld result is not separated from its context.

What does a provenance seal establish?

The content seal supports integrity checking. It is not author authentication and does not replace archiving the software, databases and inputs needed for reproduction.
