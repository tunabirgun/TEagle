Getting started

Start with a sequence.

Use a bundled example to learn the workflow, then bring your own element or locus.

Install TEagle

Download the Windows x64 installer from the 4.1.1 release. The release also includes the illustrated user manual.

The Windows bundle includes the native runtime, Qt, Primer3, HMMER and bundled TE-domain profiles. Routine use does not require a command line or a separate Python installation.

Follow your institution’s installation policy if Windows shows an unsigned-application warning.

Run the first example

  1. Launch TEagle and choose Load example element in the Start here strip.
  2. Press Run analysis and let the enabled stages finish.
  3. Read the structure and domain evidence before interpreting the classification.
  4. Open primer design when you have chosen an assay goal and a suitable region.

Use Help for the quick start and glossary. F1 opens help from the application.

Bring your own input

InputUse it for
Pasted sequence or FASTAAn element or sequence already available locally.
NCBI accessionA public reference record; retrieval needs network access.
Genomic coordinatesA defined locus in its reference context.
Bundled exampleLearning the workflow before interpreting a new specimen.

Confirm the record, orientation and sequence context. A reference sequence is not evidence that the same sequence is present in your specimen.

Add optional tools only when needed

Open BACKEND in TEagle to install, repair and verify optional WSL2 components. Dfam family annotation, splice detection and assembly functions use the optional tool stack. Review the displayed download and storage requirements first.

Public-record retrieval, tool installation and genome downloads need a connection. Analysis of already available local inputs and installed resources can run locally.

A backend stage is unavailable

Inspect its status in BACKEND, install or repair the required component, and run the integrity check. An unavailable stage is not a biological negative. Keep the status with the exported result.
