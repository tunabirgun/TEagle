# Screenshots

The present files were captured from the native TEagle 4.1.0 app in the light theme at 1920x1080, with a 1500x1150 window and UI scale 1.0. Every accepted figure is a real run: GenBank specimens (M11240 copia, M12927 gypsy, M80343 LINE, X01005 Tc1, X05424 hAT, AY037928 HERV-K113, AJ289709 HERV-H, M18706 Ty1-H3), a real NCBI coordinate fetch, a real insulin splice alignment (J00265 x NM_000207), and live WSL-backed runs (RepeatMasker/Dfam, and isPcr against the cached *Saccharomyces cerevisiae* R64 assembly, RefSeq GCF_000146045.2). The whole-genome scan figures use a Ty1 insertion that the app fetched from that same assembly by coordinate (chrII:220,000-232,000), so the designed product is bound to its genome position; the neutral-wording scan designs on the Ty1-H3 GenBank record instead, which has no genome position. No figure contains synthesised results. The capture harness is maintainer-local and is not distributed with the repository; the recapture sidecar and `screenshots/manifest.txt` record dimensions, capture conditions and what each figure shows. Optional metadata was removed from delivered PNG and SVG files after capture, with rendered-content equality verified. Original capture bindings and the derivative-verification ledger are retained in maintainer-local validation records rather than published as checksum lists. The manifest also lists manual and report figures that are kept outside the repository, so those entries cannot be opened from a clone. One of them analyses a constructed input (two head-to-tail copies of the M11240 example) to show the scope-caution strip; it is a real analysis of that constructed sequence.

These interface captures used the pre-release 4.1.0 candidate with Primer3-py 2.3.0 and pyhmmer 0.12.1. The released candidate uses the corrected dependency pins documented in the changelog; displayed dependency versions can therefore differ. The figures illustrate interface states and are not benchmark results for the final release.
